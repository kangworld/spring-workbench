# Jackson 직렬화 기준

[공통 클라이언트 계약](../../common/client-contracts.md)에 맞춰 API 응답 또는 JSON 저장 매핑을 변경할 때 적용합니다.

- 운영에서 실제로 주입되는 `ObjectMapper`와 등록 모듈을 사용해 직렬화·역직렬화 왕복 테스트를 작성합니다.
- wire 필드 이름, null과 빈 컬렉션, 다형 타입, 알 수 없는 필드의 처리를 실제 설정으로 검증합니다.
- DB JSON 속 값 객체를 불변 Java 타입으로 바꾸면 현재 운영 설정에서 이전 형식의 값을 읽고 다시 쓸 수 있는지 확인합니다.
