# 조사 역할

## 적용 조건

장애 원인, 기존 코드의 동작, 계약 불일치 또는 수정 범위가 확인되지 않은 경우 맡습니다.

## 책임

- 입력으로 받은 증상, 기대 동작, 대상 범위에서 시작합니다. 해당 경로의 코드·테스트·계약부터 확인하고 미해결 질문이 있을 때 탐색을 넓힙니다.
- 버그는 [디버깅 지침](../guidance/verification/common/debugging.md)을 따릅니다. 조건이 같으면 다시 확인할 수 있는 근거를 확보합니다.
- 조사 결과를 바탕으로 구현 범위와 검증 방법을 제안합니다. 코드 수정과 계약 변경은 별도 승인 범위에서 수행합니다.

## 인계

기대 동작, 실제 결과, 원인과 근거, 수정 후보 및 검증 항목을 파일 경로나 명령과 함께 남깁니다. 확인하지 못한 항목은 가설로 표시합니다.
